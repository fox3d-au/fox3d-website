Fox3D Scout

Search smarter. Print faster.

Scout is a multi-repository search engine designed to help makers discover printable models from one clear, transparent interface.

● In Development

Why Scout?

Finding the right model often means repeating the same search across multiple websites. Scout brings those searches together while keeping creators and original repositories at the centre.

Scout is designed to improve discovery, not replace repositories. Makers are directed back to the original source and creator.
Version 1

Planned core features

Unified search

Search selected repositories simultaneously using keywords or exact phrases.

Filters and sorting

Free, paid or both; repository selection; relevant model filters; sort by relevance, popularity or newest.

Scout Score

Transparent ranking using relevance and available quality signals.

Duplicate detection

Group likely duplicates and show every known source.

Repository status

Healthy, slow, unavailable, searching and not-selected states with response time and result counts.

Sharing

Share searches and model views using stable Fox3D links.

Search completion summary

Show results found, repositories searched and duplicates merged.

Development Mode

Admin-only diagnostics including response times, cache state, logs, session IDs and system health.

Future

Community-shaped expansion

  • Suggest and vote for additional repositories
  • Saved searches and watch alerts
  • User accounts and collections
  • AI-assisted search and recommendations
  • API, browser extension and mobile experience
